# what is software ?
 Software is a collection of programs, instructions, and data that tells a computer how to perform specific tasks.

 ## Types of Software

    -system software
    -Application Software 
      **ex : notepad | vs code | chrome**
    -Utility Software
    -Programming Software
    -networking software
        **ex : router | wireshark | zabbix 
    - web server software
         **ex : apache | iis |tomcat etc ..**
