# What is SDLC?

SDLC (Software Development Life Cycle) is a systematic process used to plan, develop, test, deploy, and maintain software.

## All Phases of SDLC
1. Planning
    Identify the project goals, requirements, resources, cost, and timeline.
2. Requirement Analysis
    Collect and analyze what the customer/user needs from the software.
3. System Design
    Design the software architecture, database, UI, modules, and overall system structure.
4. Development / Implementation
    Developers write the actual code and build the software.
5. Testing
    Test the software to find and fix bugs and verify that requirements are met.
6. Deployment
    Release the completed software to users or the production environment.
7. Maintenance
    Fix bugs, improve performance, add new features, and keep the software  updated.
