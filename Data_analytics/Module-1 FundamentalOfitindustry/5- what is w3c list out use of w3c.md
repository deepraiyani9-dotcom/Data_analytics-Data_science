# what is w3c ?
    -W3C (World Wide Web Consortium) is an international organization that develops and maintains standards for the World Wide Web (WWW).
    -w3c is an organization is managed all about web technology.
    -It was founded by Tim Berners-Lee in 1994.
    -Its main goal is to ensure that the web is open, accessible, and works consistently across different browsers and devices.

## use of w3c

        -Develops web standards.
        -Ensures browser compatibility.
        -Promotes web accessibility.
        -Improves web security.
        -Supports mobile-friendly websites.
        -Encourages internationalization (multiple languages).
        -Maintains web quality through validation.
        -Promotes an open and free web.
