# what is www ?

-WWW (World Wide Web) is a system of interlinked web pages and websites that can be accessed over the Internet using a web browser.
-www is use to access any url website using its url on web.
-It was invented by Tim Berners-Lee in 1989.
-The WWW allows users to access information, images, videos, and other online resources through web pages.
