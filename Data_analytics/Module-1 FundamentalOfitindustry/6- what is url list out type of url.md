# what is URL ?

    -URL (Uniform Resource Locator) is the address of a web page or resource on the Internet. It tells the web browser where to find a website or file.

# types of URL
   
    -Absolute URL
        -open any website of landing page or home page.
        ex : https://www.amazon.in.com
    -Relative URL
        -relative url is used to open web pages of any web application .
        ex : home.html
